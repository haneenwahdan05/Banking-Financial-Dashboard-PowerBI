# 🏦 Banking & Customer Support Performance Dashboard

## 📌 Project Overview
This repository contains a comprehensive, 5-page Power BI analytics solution designed to evaluate financial performance, loan metrics, customer activity, and support operation trends within a banking context. 

The project focuses on delivering actionable business insights through intuitive visuals, structured relational data modeling, and accurate DAX measure formulations.

---

## 🛠️ Tech Stack & Methodology
* **Business Intelligence:** Power BI Desktop
* **Data Transformation & ETL:** Power Query
* **Analytical Calculations:** Custom DAX (Data Analysis Expressions)
* **Data Architecture:** Relational Star-Schema Modeling

---

## 📊 Detailed Page Breakdowns

### 1. Overview
* **Focus:** Executive KPI Tracking
* **Details:** Summarizes high-level organizational metrics, including total account balances, overall transaction volumes, and key performance indicators required for strategic decision-making.

### 2. Customers
* **Focus:** Behavioral & Demographic Segmentation
* **Details:** Analyzes customer distribution patterns, account engagement levels, and transaction frequencies across various client segments.

### 3. Transactions
* **Focus:** Financial Movement & Liquidity
* **Details:** Tracks transfer amounts, flow velocities, and balance distributions grouped by specific account types and transaction categories.

### 4. Loans
* **Focus:** Credit Risk & Portfolio Analysis
* **Details:** Evaluates loan performance metrics, total distributions, and standardized interest rate calculations to monitor overall portfolio health.

### 5. Support Calls
* **Focus:** Service Operations & Quality Control
* **Details:** Monitors customer service performance, tracking call resolution efficiency, touchpoint volumes, and operational workload trends.

---

## ⚙️ Key Technical Highlights
* **DAX Optimization:** Standardized interest rate algorithms and scaled percentage ratios for accurate KPI modeling.
* **UI/UX Strategy:** Implemented a Clean Light Mode UI architecture (neutral base tones with high-contrast structural container layouts) for optimal visual clarity.
